# A/B-тест e-mail рассылки

> Проект в работе.

Интернет-магазин одежды разослал письма: 64 000 клиентов случайно разделили на три группы. Одной отправили письмо с мужской коллекцией, другой с женской, третьей ничего. Задача: понять, работает ли рассылка, какое письмо лучше и стоит ли слать его всем, и подтвердить это статистикой.

Данные: Kevin Hillstrom, MineThatData E-Mail Analytics Challenge (2008).

## Как запустить

```bash
pip install -r requirements.txt
jupyter notebook ab_test.ipynb
```
